### B. VPN Issues (Masalah VPN)
**Deskripsi:** Kendala akses jaringan privat virtual (VPN) untuk karyawan yang bekerja secara remote atau dari site/pabrik yang berbeda.
**Prosedur:**
1. **Pengecekan Koneksi Dasar:** Pastikan pengguna memiliki koneksi internet yang stabil di lokasi mereka.
2. **Verifikasi Kredensial & MFA:** Pastikan username, password, dan Multi-Factor Authentication (MFA) dimasukkan dengan benar.
3. **Pengecekan Aplikasi:** Pandu pengguna untuk me-restart aplikasi VPN (misal: Cisco AnyConnect/FortiClient) atau melakukan instalasi ulang jika file korup.
4. **Pengecekan Server/Network:** Jika masalah terjadi pada banyak pengguna secara bersamaan, eskalasikan ke tim Network/Infrastruktur untuk pengecekan server VPN.
5. **Penutupan Tiket:** Pastikan pengguna sudah bisa mengakses resource internal (seperti file server atau intranet), lalu tutup tiket.
